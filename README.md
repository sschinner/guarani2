# Guarani3W
Sistema de autogestion para alumnos y docentes de SIU-Guarani2. Contiene suite de servicios webs que son consumidos por otros sistemas para utilizar informacion del sistema Siu-Guarani2 y Siu-Guarani3.

# Tecnologias usadas
- PHP 5.4
- SOAP
- SVN

# Para montar en local
El directorio solo contiene informacion del codigo fuente de la aplicacion y utiliza control de versiones con Subversion.
